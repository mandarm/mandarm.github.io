Recommended books

You will need to be a little careful about what edition you use, since Python is an evolving language. All the following books are based on reasonably recent versions of Python, but please use the edition mentioned below, or a more recent one, if available.

If you are new to programming (in any language)

  • An Introduction to Programming and Computer Science with Python (2nd edition) by Clayton Cafiero, 2025 (PDF version freely available).
  • Introduction to Computer Programming with Python by Harris Wang, Open Textbook Library, 2023-2025 (EPUB, PDF and online versions freely available).
  • Introduction to Python Programming, OpenStax, Rice University, 2026 (PDF and online versions freely available).

If you have some programming experience (in any language)

  • Python in a Nutshell (4th edition) by Alex Martelli, and others, O'Reilly, 2023 (Python 3.7 through 3.11).
  • Fluent Python (2nd edition) by Luciano Ramalho, O'Reilly, 2022 (Python 3.10).
  • The Quick Python Book (4th edition) by Naomi Ceder, Manning Publications, 2025 (Python 3.9).
  • Python Distilled by David M. Beazley, Addison-Wesley Professional, 2021-2022 (Python 3.8).
